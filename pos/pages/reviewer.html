Google Play Store Review & Certification Portal

Reviewer Access & Testing Protocol.

Application: Nextora POS (Package: com.nextora.pos.mini) · Android 16 / API 36 Target

This portal provides the Google Play App Review Team with authorized, autonomous evaluation access to Nextora POS on Android without developer intervention, payment, SMS, OTP, or third-party cloud registration.

1. Application Architecture Summary

  • 100% Offline-First POS Engine: All restaurant catalog items, table states, bills, kitchen orders, inventory tallies, and receipts are stored and processed entirely in an on-device local SQLite database.
  • No Cloud Account Required: Reviewers do not need to register a cloud account or provide credentials to test full functionality.
  • Autonomous Device Licensing: The application validates review entitlements cryptographically on-device using pinned RFC-8785 Ed25519 digital signatures.
  • Independent Audit Scope: Reviewer access is explicitly categorized under GOOGLE_PLAY_REVIEW_ACCESS and distinct from normal commercial customer licenses.

3. Step-by-Step Reviewer Evaluation Walkthrough

1 Launch & Activate Software

  1. Launch Nextora POS on your Android review device or emulator.
  2. The Activate Your Software counter setup screen is presented.
  3. Paste the Reviewer Activation Code from above into the License Key or Activation Code input box.
  4. Tap Activate.
  5. The on-device Ed25519 cryptographic validator verifies the authentic signature against the pinned authority key. A success dialog appears: "Google Play Reviewer Access verified and activated successfully for this device."
  6. Tap Get Started.

2 Complete Restaurant Registration (One-Time Setup)

Enter sample testing details to initialize your local store profile:

  • Restaurant Name: Nextora Test Cafe
  • Owner / Manager Name: Play Store Reviewer
  • Phone Number: 9876543210
  • Owner Admin PIN: 8426 (Confirm PIN: 8426)
  • Tap Complete Setup & Open Counter.

3 Full POS Feature Exploration

The application immediately opens to the main POS interface with complete access to all operational modules:

  • Billing & Counter Orders: Tap menu items (Beverages, Snacks, Meals) to add to the cart. Tap View Cart, choose Dine-In or Takeaway, select Cash/UPI/Card, and tap Save & Print to generate an invoice.
  • Kitchen Order Tickets (KOT): Navigate to the KOT tab. Created orders automatically appear in the kitchen queue. Tap tickets to cycle states: PENDING → PREPARING → READY → SERVED.
  • Live Kitchen Display (KDS): Real-time synchronization with KDS counter terminals.
  • Inventory Management: Navigate to More → Inventory to view ingredient levels, low-stock indicators, and adjustment audit logs.
  • Thermal Printing: Compatible with 58mm and 80mm ESC/POS USB, Bluetooth, and Wi-Fi receipt and kitchen printers.
  • Offline Resilience: Turn on Airplane Mode; complete bills and create KOT tickets without internet interruption. Turn off Airplane Mode with zero crashes.
