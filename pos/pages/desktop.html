What it does

Built around the counter workflow

Every screen serves the daily billing loop — nothing more, nothing missing.

BillingItemsBills SettingsPrinterBackup LicenseUpdates
  • Offline-first billing — billing runs on locally stored data and continues when the network drops.
  • Fast item selection — organized items with quick search to move from selection to bill in seconds.
  • Bill generation — numbered bills with itemized totals, ready for the counter workflow.
  • Thermal receipt printing — print receipts on supported ESC/POS thermal printers.
  • Item management — add, edit and organize the items your counter sells every day.
  • Local backups — export backups to a file and restore them when moving or recovering data.
  • License activation — activate your device with the annual license key supplied by Nextora.
  • Software updates — check for and install supported product updates from within the app.
